# Coupon Page Freshness Detector

A lightweight tool that analyzes coupon and promotional pages for potential freshness issues.

### Checks

* 📅 Outdated year/date references
* 🎟️ Potentially expired offers
* 🔗 Broken links
* 🏷️ Promotional and seasonal content
* 📝 Page update signals
* 📊 Freshness score

### Demo

Enter a coupon page URL and get a simple freshness report with recommended actions.

### Tech

Built with **HTML, CSS & JavaScript**. The frontend can be hosted on GitHub Pages.
